# THE SINGLE DOMINO COMPRESSION TOOL
Author: Eric Weiss  
Purpose: Force Ruthless Focus on the One Lever That Moves the System  
Audience: Founder / CEO  

---

# 1. PURPOSE OF THIS TOOL

Founders say they lack time.

They do not lack time.
They lack compression.

Common pattern:

- 5 priorities
- 7 initiatives
- 3 strategic bets
- Constant context switching
- Calendar fragmentation
- Team diffusion

Result:

- No compounding progress
- Energy dilution
- Mediocre outcomes across the board

The Single Domino Compression Tool forces:

One primary win.
Everything else subordinate.

---

# 2. WHEN TO USE

Use when:

- Founder overwhelmed
- Team juggling multiple initiatives
- Quarterly goals scattered
- No visible momentum
- Resources thin
- Strategy unclear
- Calendar full but impact low

If everything matters, nothing compounds.

---

# 3. STEP 1 — CURRENT PRIORITY INVENTORY

List:

All current initiatives.

Include:

- Revenue projects
- Hiring goals
- Product bets
- Fundraising prep
- Operational upgrades
- Brand initiatives
- Personal performance goals

No filtering.

See the sprawl.

---

# 4. STEP 2 — LEVERAGE RANKING

For each initiative ask:

If this succeeds, what downstream problems disappear?

Score each 1–5 on:

| Dimension | Score |
|------------|-------|
| Revenue impact |
| Strategic leverage |
| Risk reduction |
| Morale impact |
| Founder relief |
| Compounding effect |

The highest compounding initiative is candidate domino.

---

# 5. STEP 3 — ELIMINATION PHASE

Ask:

If we could only win one thing this quarter, what would it be?

Force decision.

Then ask:

What must we explicitly deprioritize to make this real?

Remove:

- Time allocation
- Calendar slots
- Resource allocation
- Meeting frequency
- Headcount focus

Compression requires sacrifice.

---

# 6. STEP 4 — CALENDAR REALLOCATION

Audit:

Founder calendar for next 4 weeks.

Ask:

Does calendar reflect chosen domino?

If not:

- Remove low-leverage meetings
- Reassign ownership
- Block focus time
- Cancel optional initiatives
- Reduce noise

Calendar reveals truth.

---

# 7. STEP 5 — TEAM ALIGNMENT DECLARATION

Founder must declare:

“This quarter, the primary objective is X. Everything else supports it.”

Clear.
Simple.
Repeated.

Ambiguity destroys compression.

---

# 8. STEP 6 — LEADING INDICATOR IDENTIFICATION

Define:

What weekly metric proves progress on this domino?

Examples:

- Qualified pipeline volume
- Weekly active users
- Feature adoption rate
- Conversion rate
- Demo-to-close ratio
- Deployment frequency

Measure weekly.
Adjust weekly.

---

# 9. STEP 7 — DOMINO DEFENSE PROTOCOL

Define:

What will try to distract us?

Examples:

- New feature requests
- Investor noise
- Shiny opportunities
- Competitive moves
- Internal pet projects

Pre-commit:

“Unless it directly accelerates X, it waits.”

---

# 10. FAILURE MODES

AI must guard against:

- Allowing multiple primary objectives
- Soft deprioritization
- Keeping optional initiatives alive
- Ignoring calendar misalignment
- Founder not publicly committing
- Selecting vanity goal instead of leverage goal

Compression creates momentum.

---

# 11. AI IMPLEMENTATION RULES

If another AI runs this tool:

It must:

1. List all initiatives.
2. Score leverage.
3. Force single domino selection.
4. Identify sacrifices.
5. Audit calendar alignment.
6. Define weekly metric.
7. Script public declaration.
8. End with calendar change commitment.

Tone:

- Direct
- Unapologetic about tradeoffs
- Strategic
- Focus-driven
- Calm

Never:

- Allow “top three priorities.”
- Accept vague focus statements.
- Avoid calendar audit.
- End without sacrifice.
