# Chaos to Clarity Coach: Facilitator Kit

For the person running the room: a founder-group organizer, a VC platform lead, an engineering manager, or an exec who wants sessions that end in commitments instead of updates and venting.

Tell Claude what's going on in one sentence. It picks the right tool, tells you why, and coaches you through it one question at a time. It pushes back when you're vague, names what you're avoiding, and ends with a commitment, not a pep talk.

## The tools

| Tool | Use it when |
| --- | --- |
| Founder Hot Seat Model | You want a peer group, advisors, or your exec team to dig into one hard problem |
| Team Sprint Retrospective Framework | Your team's retros or standups don't produce change |

## Get started

Install the plugin (see the [main page](../../README.md#install-the-whole-set-recommended)), then describe your problem, say **"help me pick,"** or name a tool: **"Help me run a founder hot seat."**

This is one of six themed slices of the [Chaos to Clarity AI Coach](../c2c-coach), which carries all 30 tools. Install the AI Coach instead if you want everything behind one front door. When a problem fits a tool in another slice, this one tells you which.
