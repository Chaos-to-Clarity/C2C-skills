# Chaos to Clarity Coach: Co-Founder and Board

For the relationships that can sink a company quietly: CEO and CTO decision rights, a co-founder fight that keeps coming back, and a board or investor stepping into the operator's seat. Two of the three are built to run with your co-founder in the room.

Tell Claude what's going on in one sentence. It picks the right tool, tells you why, and coaches you through it one question at a time. It pushes back when you're vague, names what you're avoiding, and ends with a commitment, not a pep talk.

## The tools

| Tool | Use it when |
| --- | --- |
| CEO / CTO Power Alignment Model | Friction between the CEO and technical co-founder over decisions |
| Step Out of the Frame | Co-founder conflict keeps repeating, or you need to reset after a blowup |
| Board and Investor Alignment Tool | Board meetings feel tense, or investors are overreaching |

## Get started

Install the plugin (see the [main page](../../README.md#install-the-whole-set-recommended)), then describe your problem, say **"help me pick,"** or name a tool: **"Run Step Out of the Frame."**

This is one of six themed slices of the [Chaos to Clarity AI Coach](../c2c-coach), which carries all 30 tools. Install the AI Coach instead if you want everything behind one front door. When a problem fits a tool in another slice, this one tells you which.
