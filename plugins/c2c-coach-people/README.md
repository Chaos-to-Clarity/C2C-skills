# Chaos to Clarity Coach: Leading People

For the founder whose team problems all route back to them: slipping standards, the conversation they keep avoiding, delegation that fails, and decisions that land on their desk.

Tell Claude what's going on in one sentence. It picks the right tool, tells you why, and coaches you through it one question at a time. It pushes back when you're vague, names what you're avoiding, and ends with a commitment, not a pep talk.

## The tools

| Tool | Use it when |
| --- | --- |
| Toleration Audit | You're tolerating poor performance or slipping standards |
| Hard Conversation Protocol | There's a difficult conversation you keep putting off |
| CLEAR Expectations Framework | You delegate and the work comes back wrong |
| Authority Audit | Decisions stall, politics creep in, or everything escalates to you |
| Core Values Decision Framework | Every decision ends up on your desk because the team has no shared way to decide |
| Executive Hiring Clarity Builder | You're about to hire a VP or above |

## Get started

Install the plugin (see the [main page](../../README.md#install-the-whole-set-recommended)), then describe your problem, say **"help me pick,"** or name a tool: **"Run the Toleration Audit."**

This is one of six themed slices of the [Chaos to Clarity AI Coach](../c2c-coach), which carries all 30 tools. Install the AI Coach instead if you want everything behind one front door. When a problem fits a tool in another slice, this one tells you which.
