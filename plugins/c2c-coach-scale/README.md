# Chaos to Clarity Coach: Org and Scaling

For the company that has outgrown heroics: no operating rhythm, teams stepping on each other, numbers nobody owns, one function dragging the rest, and a growth plan that will break something.

Tell Claude what's going on in one sentence. It picks the right tool, tells you why, and coaches you through it one question at a time. It pushes back when you're vague, names what you're avoiding, and ends with a commitment, not a pep talk.

## The tools

| Tool | Use it when |
| --- | --- |
| Chaos to Clarity Operating Model | You're firefighting with no system, and you need to find where the chaos really lives |
| Object-Oriented Management | Teams step on each other and ownership between them is unclear |
| Founder Scorecard System | You can't tell if you're making progress, or nobody owns the numbers |
| Functional Scaling Redesign | One function is underperforming and dragging the company down |
| Exponential Scaling Playbook | Growth keeps breaking things, or you're scaling on heroics |
| Exponential Department Exercise | You're about to grow fast and want to find what breaks first |

## Get started

Install the plugin (see the [main page](../../README.md#install-the-whole-set-recommended)), then describe your problem, say **"help me pick,"** or name a tool: **"Run the Founder Scorecard System."**

This is one of six themed slices of the [Chaos to Clarity AI Coach](../c2c-coach), which carries all 30 tools. Install the AI Coach instead if you want everything behind one front door. When a problem fits a tool in another slice, this one tells you which.
